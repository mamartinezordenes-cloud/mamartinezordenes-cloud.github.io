Sobre mí

De la idea al código, sin perder de vista a quien lo usa

Soy Trainee en desarrollo Full Stack con foco en Java. Disfruto tanto armar la lógica de negocio y el acceso a datos como cuidar el detalle de la interfaz que finalmente ve la persona usuaria. Vengo formándome en patrones de arquitectura (MVC, DAO), buenas prácticas de seguridad y en frameworks modernos como Spring Boot, sin dejar de lado el front-end con HTML, CSS, JavaScript y Bootstrap.

Trabajo con orden: control de versiones con Git, código documentado y decisiones de diseño que puedo explicar. Este portafolio reúne tres proyectos que muestran ese recorrido, del navegador al servidor.

Proyectos

Tres proyectos, tres capas del desarrollo

De una interfaz web pensada para el usuario final, a un sistema Java con acceso a datos, hasta una aplicación Spring Boot con seguridad y API REST.

Alke Wallet

Billetera digital pensada para simular operaciones bancarias cotidianas: iniciar sesión, ver saldo, depositar, enviar dinero y revisar el historial de movimientos. El estado se guarda en localStorage para que la experiencia se sienta persistente sin backend.

  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap 5
  • jQuery
Ver demo en vivo Ver código

Biblioteca Digital UNTEC

Aplicación web en Java EE para administrar el catálogo, los préstamos y los usuarios de una biblioteca. Arquitectura MVC con capa DAO (patrón Singleton para la conexión), servlets para login y gestión de libros/préstamos, y persistencia en base H2, desplegada sobre Apache Tomcat.

  • Java
  • Servlets
  • JSP / JSTL
  • Maven
  • H2
Ver código

SpringEduManager

Sistema de gestión de alumnos construido con Spring Boot: CRUD completo con validaciones de formulario, vistas en Thymeleaf y una API REST paralela para consumo externo. Incluye Spring Security con usuarios en memoria, contraseñas cifradas con BCrypt y roles ADMIN / USER que restringen quién puede crear, editar o eliminar registros.

  • Java
  • Spring Boot
  • Spring Security
  • Spring Data JPA
  • Thymeleaf
